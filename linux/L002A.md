# L002a: tree and continuous thumbnail browser

Status: source candidate authored; use the associated CI run to determine compilation/integration status. New native-GNOME desktop acceptance is pending. This file will receive the completed CI record after the candidate checks finish.

## Changes

The Linux app is 0.1.0-alpha.2 and its title includes L002a. The directory sidebar is now an expandable Home/File system tree with asynchronous one-level loading, retained ancestors, natural ordering and link leaves. The thumbnail area is a continuous pixel-scrolling virtual canvas with viewport-plus-one-row overscan controls, two-line captions, cancellation/disposal when recycled, keyboard navigation and resize reflow. Tabs use the same session schema/location. Returning to Browser restores the folder-count status.

## Automated coverage added

- Viewport arithmetic across empty/small/large counts, tiny/large viewports, extreme offsets and non-finite offset input.
- One-level directory listing, natural ordering, Unicode/case-sensitive paths, marked symbolic links, cancellation and missing-directory errors.
- X11 window integration: continuous scrolling beyond 72 items, resize, bounded live tile counts with 100k synthetic entries, corrupt/missing image placeholders, recovery, retained tree ancestors and rapid navigation.
- Thumbnail button route, exact-path tab deduplication, hidden-browser disposal and saving the remaining tabs after closing one.
- A fresh process restores the folder without a command-line override, ordered tabs, selected image and closed-tab exclusion; Browser status is then checked.

The original sorting/session console tests remain part of the check script. All fixtures and session data are disposable. The synthetic 100k entries reuse paths to 120 generated PNG files; this is not a real-image throughput or memory benchmark. UI screenshots, when generated, use those fixtures only and do not establish a human visual review.

## Nova acceptance after updating

Close the old app normally before updating the clean linux/ubuntu-gnome checkout. Run bash linux/check.sh and bash linux/run.sh. Expect L002a in the title, an expandable folder tree and no page buttons. Browse the existing screenshot folder, scroll beyond the old first page, resize the browser and navigate to a child and back through the tree. Check long-name tooltips and that returning from an image tab shows the folder count. Recheck tab restoration with one closed tab and a different active image.

Zoom/pan, advanced codecs, disk caching, preloading, incremental file publication, a virtualised directory tree, real 100k-folder performance, native Wayland and GPU validation are not included in this change. No Windows source/interface/version/build changes are intended; the baseline isolation and final diff must confirm this before advancing the Linux branch.
